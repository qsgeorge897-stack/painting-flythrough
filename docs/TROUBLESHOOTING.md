# 常见问题与解决办法

## 画面瑕疵

| 现象 | 原因 | 解决 |
|---|---|---|
| 物体边缘拖出长长的条纹、拉丝 | 深度突变处的网格三角形被拉长 | 调小 `worlds.json` 的 `edge`（0.25–0.3）；大的近景主体加 `--edge-dilate`；用 `--debug noFg` 确认是不是前景网格造成的 |
| 主体侧面露出灰块、色块 | 背景层在主体背后是"模糊的原画"，颜色和深度都不对 | 在画作专属脚本里把主体背后的背景层深度设成远景、颜色借邻近区域（`starry_night.py` 第 5 段） |
| 画面里出现第二个镜像的主体 | 画布外的区域是镜像延伸出来的 | 画布外的前景网格不画，只留背景层（`flow: true` 的画已经这样处理） |
| 镜头一偏就看到画布外的空白 | 外延不够 | `prep_world.py --margin 0.45` |
| 光晕被切成半圆或斜边 | 光晕贴片和天空网格相交 | 光晕沿视线往前放（`openZ(...) * 0.8`） |
| 星星过曝成白色圆盘 | 光晕和泛光太强 | 光晕核心约 0.3，`bloom` 0.35，`bloomTh` 0.6 |
| 展开时出现一块块硬边，像纸板 | 用了旧的分层弹出（`uOpen` < 1） | 用 `uFlat` 连续展开，`uOpen = uSmooth = 1` |
| 镜头前面飘过放大的浅色碎片 | 离相机太近的笔触粒子 | 着色器里按距离淡出（`near` 系数），或调低 `uStrokeA` |
| 整个画面像蒙了一层雾 | 开了油画滤镜 `paint` 或景深太大 | `paint: 0`，`aper` ≤ 0.08 |
| 天空凹凸、漩涡展开时被撕裂 | 模型把天空的笔触当成了物体 | 用遮罩把天空压成一个光滑的远景壳 |
| 笔触云一片糊，看不出结构 | 笔触太小太多、颜色单一 | 减少笔触数量、加大 `uStrokeScale`，或在亮部保留笔触形状（`keep`） |

## 渲染

| 现象 | 解决 |
|---|---|
| `load error` / 黑屏 | 这个 cut 需要的素材没准备好（看 `film.js` 末尾的 `NEEDS`），或者 `worlds.json` 里缺这幅画 |
| `PAGE THREE.WebGLProgram: Shader Error` | 着色器编译错误，日志里有出错的行号和上下文，多半是新加的 uniform 没声明 |
| 太慢 | `--gpu`（有显卡时）；先 `--w 960 --h 540`；只渲关键帧 `--times` |
| 渲染中断了 | 直接重跑同一条命令，已有的帧会跳过 |
| 找不到浏览器 | 设 `CHROME_PATH=/path/to/chrome`，或 `npx playwright install chromium` |

## 素材与发布

| 现象 | 解决 |
|---|---|
| Wikimedia 返回 HTTP 429 | 正常限流，脚本会自动等待重试；批量下载之间 `sleep 5` |
| 芝加哥艺术博物馆 IIIF 返回 403 | 有 Cloudflare 拦截，改用 Commons 上同一幅画 |
| 视频超过聊天软件 30 MB 上限 | `encode.sh` 降码率：码率(kbps) × 秒数 / 8 / 1024 < 28 MB |
| 字体缺失、中文变方块 | `apt install fonts-noto-cjk`，或 `caption.py --font` 指向系统中文字体 |
