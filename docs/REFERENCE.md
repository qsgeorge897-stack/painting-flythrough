# 引擎参数速查

## `web/data/worlds.json`（每幅画一条）

| 字段 | 含义 | 常用值 |
|---|---|---|
| `fov` | 画作宽度对应的水平视角（度）。画布放在离相机 `D` 的地方，正好铺满这个视角 | 60–64 |
| `D` | 画布平面离相机的距离（`uFlat = 0` 时所有点都在这里） | 1.2–1.8 |
| `zn` / `zf` | 最近 / 最远的点离相机多远。`zf/zn` 越大纵深越夸张 | 天空画 2 / 60；花园 1.6 / 20 |
| `gamma` | 深度曲线：视差 d → 距离 `z = zn·(zf/zn)^((1−d)^gamma)`。大于 1 时中景被推远 | 1.0–2.2 |
| `edge` | 深度突变剔除阈值（对数深度的局部变化）。越小切得越狠，空洞越多、拉丝越少 | 0.25–0.3 |
| `layers` | 旧版"立体书分层弹出"用的层数（`uOpen`），新流程不用 | 7 |
| `clear` | 背景清屏色（偶尔露出空隙时看到的颜色） | 画里最远处的颜色 |
| `flow` | `true` 表示加载 `<name>_flow.png` 和 `<name>_lights.json` | — |

## PaintWorld 控制量：`worlds.<name>.set({...})`

每帧在 cut 函数里设置，全部是 0–1 之间平滑变化的值（用 `ramp()`）。

| 控制量 | 作用 |
|---|---|
| `uFlat` | **2D↔3D 主开关**。0 = 平面原画，1 = 完全按深度展开。点只沿视线移动，所以从 HOME 看投影不变 |
| `uVol` | 天空笔触散成体积云的程度（散开到原深度的 50–100%）。亮黄色笔触（星、月）不散开 |
| `uFlowAmt` | 画面沿流向场流动的强度（2D 网格纹理平移 + 笔触沿流向漂移） |
| `uGlow` | 光源光晕强度（呼吸、光环转动） |
| `uStrokeA` | 笔触粒子的不透明度。展开时淡入，收回时淡出，避免平面状态下有重影 |
| `uStrokeScale` | 笔触大小倍数（星月夜用 0.8） |
| `uFly` | 旧版：一小部分笔触飞出画框漂在空中（展厅开场用） |
| `uGal` | 画面暗角（展厅里聚光灯打在画上的效果） |
| `uOpen` / `uSmooth` | 旧版"立体书"分层展开，新流程保持 1 |
| `uTime` | 动画时间，传 `t` |

## 镜头对象 `sh`（cut 函数返回 `{ sh, zoom, fade, cur }`）

| 字段 | 含义 |
|---|---|
| `scene` | 要渲染的场景（`worlds.x.scene` / `micro.scene` / `pond.scene` / `OW.scene`） |
| `pos` / `look` | 相机位置、注视点。用 `track([[t, [x,y,z], ease], ...], t)` 做关键帧插值；ease 可选 `'in'` `'out'` `'io'` |
| `roll` | 相机绕视线旋转（弧度），穿漩涡时用 |
| `hfov` | 输出画面的水平视角（度）。比画的 `fov` 略小 = 铺满 16:9 的整屏原画 |
| `near` / `far` | 裁剪面 |
| `focus` / `aper` | 景深：对焦距离、光圈（0 = 全清晰，0.03–0.1 有明显虚化） |
| `gradeA` / `gradeB` / `gmix` / `sweep` | 调色预设（见 `GRADES`）及其混合；`sweep` 让新色调从画面一侧扫过来 |
| `fogStart` / `fogMul` | 距离雾 |
| `vig` | 暗角强度 |
| `bloom` / `bloomTh` | 泛光强度 / 阈值 |
| `paint` | Kuwahara 油画滤镜（试验功能，会让画面发糊，默认 0） |
| `clear` | 清屏色 |
| `before(cam)` | 渲染前回调（例如让天空球跟着相机） |

返回值里另外三个：
- `zoom`：径向速度模糊，0–0.3
- `fade`：整体亮度（0 = 黑场），用来做开头淡入、结尾淡出
- `cur`：遮挡转场 `{ u: -1..1, ty: 0|1|2 }`，0 = 鸢尾叶，1 = 柳枝，2 = 暗场花拱；纹理区域在 `CURTEX`

## 坐标系

- 相机 HOME 在原点，朝 −z 看，y 向上。
- 画上 (u, v)（左上角为 0,0）在深度 z 处的位置：`x = (u − 0.5)·2·tanX·z`，`y = (0.5 − v)·2·tanY·z`，`tanX = tan(fov/2)`，`tanY = tanX·H/W`。
- 想让 HOME 构图中心落在画的 v₀ 处：相机 y = (0.5 − v₀)·2·tanY·(D + 0.012)，看向同一高度的 z = −10 处。

## 渲染器 `web/render.js`

```
--cut NAME  --out DIR  (--range S E --fps N | --times a,b,c)  [--w 1920 --h 1080] [--gpu] [--quality 0.94] [--debug noFg,noBg,noSt,noGl]
```
环境变量 `CHROME_PATH` 指定浏览器；默认自动找 Playwright 自带的 Chromium、系统 Chrome。
