# 分镜模板与实例

## 模板

复制这张表，每行一个镜头段落。**"2D/3D 状态"这一列必须填**，这样写代码时就知道 `uFlat` / `uVol` 什么时候变化。

| 时间 | 画面（镜头怎么动、看到什么） | 2D/3D 状态 | 转场 / 衔接方式 | 关键参数 |
|---|---|---|---|---|
| 0–1 秒 | 整屏原画，静止 | 纯 2D | — | HOME 视角 |
| 1–4 秒 | 画活了：……在动、……在发光 | 2D 动画 | — | `uFlowAmt` `uGlow` `bloom` |
| 4–8 秒 | 镜头推近，……浮出，……展开 | 2D→3D | 同一画面连续展开 | `uFlat` 0→1 |
| … | … | 全 3D | 穿过……（画内遮挡物） | `zoom` |
| … | 后撤，回到画家视角 | 3D→2D | 同一画面连续收回 | `uFlat` 1→0 |
| 最后 5 秒 | 整屏原画 + 字幕 | 纯 2D | — | caption.py |

时长建议：抖音 25–40 秒。最后至少留 4 秒给整屏原画和字幕。

## 实例 1：梵高《星月夜》（`--cut starry`，32 秒）✅ 推荐模板

| 时间 | 画面 | 2D/3D 状态 | 关键参数 |
|---|---|---|---|
| 0–1 秒 | 整屏《星月夜》 | 纯 2D | HOME：相机在原点，看 v = 0.43 处 |
| 1–4 秒 | 漩涡沿笔触方向流动，星星、月亮、窗灯亮起，光环转动 | 2D 动画 | `uFlowAmt` 1→2.6 秒淡入，`uGlow`，`bloom 0.35` |
| 4–8 秒 | 镜头缓推，柏树向前浮出，天空笔触脱离画布成笔触云 | 2D→3D | `uFlat` 4→7.5 秒，`uVol` 5→8.5 秒，`aper` 渐增 |
| 8–13 秒 | 擦过柏树往上飞，从发光的星星旁边掠过 | 全 3D | 轻微 `zoom` 0.02 |
| 13–17 秒 | 钻进笔触云，顺着大漩涡方向侧旋 | 全 3D | `roll` 到 −0.42 |
| 17–21 秒 | 穿出漩涡飞向月亮，月牙逐渐清晰 | 全 3D | 月亮、星星笔触不散开（保持形状） |
| 21–25 秒 | 快速后撤，倒着穿过柏树（画面一暗），立体层收回 | 3D→2D | `zoom` 0.06，`uVol` 24→26.5，`uFlat` 24.6→27 |
| 25–32 秒 | 停回画家视角，漩涡慢慢停下，定格整屏原画，字幕 26.6 秒淡入 | 纯 2D | `uFlowAmt` 26.5→28.6 淡出 |

原计划 18–22.5 秒还有一段"俯冲向村庄"，因为村庄在画里太小、又被柏树挡住，单张画的立体数据撑不住近距离俯冲，最后砍掉了。

## 实例 2：莫奈《花园小径》→《睡莲池》（`--cut fusion2`，38.5 秒）

| 时间 | 画面 | 2D/3D 状态 | 衔接 |
|---|---|---|---|
| 0–3 秒 | 昏暗展厅，聚光灯下的《吉维尼花园小径》，镜头缓推 | 纯 2D（带画框） | — |
| 3–8 秒 | 画面长出纵深，笔触飘出画框，镜头侧移 | 2D→3D | `uFlat` 平滑展开 |
| 7–10 秒 | 画框和墙从画的边缘被"化掉"，花园铺满画面 | 3D | 画廊着色器 `uDiss` |
| 10–14.5 秒 | 沿小径缓缓起步、加速，冲进尽头花拱 | 3D | 花拱暗场遮挡（curtain 2） |
| 14.5–20.9 秒 | 贴着《睡莲》（1906）水面低飞 | 2.5D 地形 | 穿过鸢尾叶（curtain 0） |
| 20.9–29 秒 | 《睡莲池》立体空间，飞向日本桥，升进垂柳 | 3D | 柳枝铺满画面（curtain 1） |
| 29–38.5 秒 | 柳枝散开，退回画家视角，压平成整屏原画，字幕 | 3D→2D | `uFlat` 平滑收回 |

这一版的问题：一共用了 3 次遮挡转场、4 幅画，叙事是串起来的而不是一个世界；睡莲水面笔触太柔，放大后发糊。所以《星月夜》改成了只用一幅画、全片不转场。
