# 视觉设计原则

这些原则是做《睡莲》《花园小径》《星月夜》时反复返工总结出来的。每条后面写了当时出了什么问题。

## 一、2D 和 3D 的衔接

**1. 从画家视角看，3D 场景必须正好拼回原画。**
所有立体元素（深度网格、笔触粒子、光晕）都放在"画家视角穿过原像素"的那条视线上。这样展开前后、收回前后都是同一个画面，不需要转场。
（最早的版本把画切成 7 层像立体书一样"弹"出来，每层边缘有明显的硬边，看起来像纸板。改成按深度连续展开 `uFlat` 以后才顺。）

**2. 展开要慢，铺开要有过程。**
从平面到立体至少用 3–4 秒，镜头同时缓慢推进或侧移，让人感觉到纵深在"长出来"。
（"画框打开"的第一版只用了 1 秒，用户反馈"突兀"；改成画面先长出纵深、再把画框和墙从边缘一点点化掉以后才自然。）

**3. 不要往画的世界里放外来的东西。**
悬浮在空中的画框、程序生成的 3D 山谷、卡通树，和原画的笔触放在一起会显得诡异。整个视频里能看到的东西，都应该来自画本身。
（"开放世界"版用代码搭了一个莫奈风格的山谷，画框悬在空中，用户反馈"一幅画在开放世界中感觉很诡异"。）

**4. 2D/3D 融合优于纯 3D。**
单张画只有一个视角的信息，镜头偏离太远就会露馅。好的路线是：大部分时间在"画家视角附近 ±30°"活动，深入时钻进笔触云或从近景遮挡物中穿过，不要绕到物体背后去看。

## 二、转场

**5. 用画里的东西遮挡转场。**
镜头穿过柏树、花拱、柳枝、一丛鸢尾叶，在被遮挡铺满画面的那一帧切换场景，观众看不出接缝。遮挡物的纹理直接取自原画（`compMat` 的 curtain，纹理区域在 `CURTEX`）。

**6. 能不切就不切。**
一幅画内部的所有运动都应该是连续的，只有换画的时候才需要遮挡转场。《星月夜》全片没有一次转场，比用了三次遮挡的莫奈版更顺。

**7. 不要把几幅画拼成"同一幅画的四季"。**
这样拼会误导观众。想做时间变化，要么用同一系列（例如莫奈《干草堆》同一构图的不同季节），要么用调色模拟一天的光影，并且在文案里如实说明。

## 三、节奏

**8. 第 1 秒就是整幅画，3 秒内必须有变化。**
抖音的观众前 3 秒就会划走。开场直接是整屏原画（让人认出来是哪幅名画），然后画立刻"活"过来：漩涡流动、星星发光。

**9. 前快后慢。**
中段冲刺加径向模糊（`zoom`），结尾减速，稳稳停在原画上。参考视频的结构是：一开场就沉浸高速穿行 → 中段暗场转换 → 退出揭晓原画 + 字幕。

**10. 首尾呼应，结尾整屏原画 + 字幕。**
结尾停在和开头同一个构图的整屏原画上，打出"作者 ｜ 画名 年份 ｜ 材质 ｜ 馆藏 尺寸"。字幕下面加一条深色渐变，保证在复杂的画面上也看得清。

**11. 变速：重点常速，铺垫加速。**
需要缩短时长时，不要整体加速。展开、穿越、定格这些关键时刻保持 1.0–1.1 倍，飞行段 1.5–2 倍，速度变化平滑过渡（`retime.py`）。

## 四、画面质感

**12. 别用"油画滤镜"糊住画面。**
试过 Kuwahara 滤镜 + 沿笔触涂抹，想让 3D 场景更像油画，结果整个画面像蒙了一层雾。原画本身已经有笔触，保持清晰更好（`paint: 0`）。

**13. 光要克制。**
光晕的核心亮度控制在 0.3 左右，泛光阈值 0.6。第一版星星直接过曝成白色圆盘，失去了梵高的笔触。光晕要沿视线往前放（深度 ×0.8），否则会被天空网格切成半圆。

**14. 笔触云要能看出结构。**
笔触沿流向场移动，并按自己的生命周期淡入淡出，看起来像在流动，而不是一群静止的碎片。天空笔触散开到原深度的 50–100%，亮黄色的星星、月亮笔触不散开，保持形状完整。

## 五、选题

**15. 选"能拆开"的画**（详见 [WORKFLOW.md 第 0 步](WORKFLOW.md#0-选画)）：前后层次分明、有能动的元素、有光源、有近景遮挡物、笔触鲜明。
《星月夜》完美符合；莫奈的睡莲水面平、笔触柔，做出来始终不够惊艳。下一批推荐：梵高《夜间露天咖啡座》《罗纳河上的星夜》《麦田群鸦》、北斋《神奈川冲浪里》、莫奈《日出·印象》、克里姆特《吻》（金色适合发光）。
